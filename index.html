      What the scale says

        recent weigh-inssame date again overwrites

          A phase is a stretch of time with its own targets. Each runs from its start date until the next one begins, so old days keep being scored against the goals you actually had then. Anything you change here shows up in the log and stats right away.

          Starting a bulk later? Add a phase dated the day you plan to begin, then hit scale on it to raise every target by a percentage as a starting point. Nothing before that date changes.

          Export

          Daily totals for every logged day, as CSV. Use it to refresh macro_data.csv in your repo.

          Import

          Paste rows as date,calories,protein,carbs,fat — one per line, dates as YYYY-MM-DD. A header row is fine. Imported days replace whatever is on those dates.

          Reset

          Clears everything in the shared database — entries, favorites, phases, weigh-ins, for anyone using this app — and restores the original sheet history and default phases.
